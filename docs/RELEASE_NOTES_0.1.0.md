# 项目管理看板 0.1.0 发布说明

发布日期：2026-08-09

发布状态：首个个人使用版，Windows x64 验收通过

## 核心能力

- 创建具有独立字段和业务术语的数据库。
- 使用字段类型、记录、状态完成语义和归档恢复管理事务。
- 为每个数据库保存独立的字段布局、筛选和排序视图。
- 在一个纵向看板中组合多个数据库视图。
- 生成无交互控件的静态报告预览。
- 下载可编辑多工作表 Excel 和自动合并布局的单工作表展示版 Excel。
- 在 Windows 经典 Outlook 中创建可见草稿，并提供富文本复制和 HTML 下载后备方式。
- 创建和验证完整工作区备份，在受控重启时恢复，并在失败时自动回滚。
- 使用自带 Node.js 24.19.0 的离线 Windows x64 便携包运行。

## 安全和数据

- 服务固定监听 `127.0.0.1`。
- 数据默认保存在 `%LOCALAPPDATA%\ProjectManagerDashboard`，不会写入发布目录。
- 发布包启动前验证完整的 SHA-256 文件清单。
- Outlook 适配器不接受收件人、附件、任意脚本或任意 HTML，也没有保存或发送邮件的代码路径。
- HTML 和 Excel 导出会转义或中和不可信文本。

## 验收结果

- Windows x64 上完成冻结依赖安装，无需 C/C++ 编译工具链。
- 使用固定 Node.js 24.19.0 运行时加载并查询了便携包内的原生 SQLite 模块。
- 生成并验证 `ProjectManagerDashboard-0.1.0-win-x64.zip`。
- 用户于 2026-08-09 确认 Windows 验收矩阵完成，包括断网首次启动、数据持久化、启停、篡改拒绝、Excel 两种导出、经典 Outlook 草稿与后备方式、备份恢复、失败回滚和升级流程。
- 集成后的跨平台自动验证包含 57 项测试，并通过 lint、生产构建和格式检查。

## 已知边界

- 支持 Windows 10/11 x64 和 Windows 经典 Outlook；其他 Outlook 版本不属于首版兼容范围。
- 便携启动器未进行商业代码签名，单位终端策略可能需要 IT 明确允许。
- 首版是单人本地应用，不包含账号、云同步、LAN 服务或实时协作。
- CSV/XLSX 导入、关系/汇总/公式字段、看板多列布局、日历、时间线和提醒属于后续候选能力。

安装、使用、升级和恢复步骤见 [用户手册](USER_GUIDE.md)。

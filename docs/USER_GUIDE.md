# 项目管理看板 0.1.0 用户手册

## 1. 适用范围

项目管理看板是一款单人、本地优先的 Windows 应用。它像 Notion 的内嵌表格一样，在一个网页工作台中纵向显示多个结构完全不同的表格。数据保存在本机 SQLite 文件中，应用正常使用时不需要互联网。

首版支持 Windows 10/11 x64。创建 Outlook 草稿需要 Windows 经典 Outlook；如果本机没有经典 Outlook，仍可复制富文本或下载 HTML。Excel 导出文件使用桌面 Excel 打开效果最佳。

## 2. 安装和首次启动

1. 获取可信来源提供的 `ProjectManagerDashboard-0.1.0-win-x64.zip`。
2. 将 ZIP 完整解压到当前用户可写的本地目录，例如 `C:\Users\你的用户名\Apps\ProjectManagerDashboard-0.1.0`。不要直接在 ZIP 内运行，也不要放到需要管理员权限的 `Program Files`。
3. 双击 `verify-release.cmd`。看到完整性检查成功后再继续。
4. 双击 `start-dashboard.cmd`。
5. 等待默认浏览器打开 `http://127.0.0.1:4300`。
6. 第一次进入后确认右上角显示“已保存到本机”。数据目录位于 `%LOCALAPPDATA%\ProjectManagerDashboard`。

便携包已经包含 Node.js 运行时，目标电脑不需要安装 Node.js、pnpm 或数据库软件。应用只监听本机回环地址，局域网内的其他电脑无法访问。

### 日常启动和停止

- 启动或重新打开页面：双击 `start-dashboard.cmd`。重复启动不会创建第二个后端进程。
- 关闭浏览器标签页：只关闭界面，不会停止本地服务。
- 完整停止应用：双击 `stop-dashboard.cmd`。
- 页面没有自动打开时：手动访问 `http://127.0.0.1:4300`。

## 3. 基本工作方式

打开应用后会直接进入“项目工作台”。正常使用时不需要手工创建视图、看板或区块，系统会在内部自动完成这些关系：

```text
一个工作台页面 → 多个独立表格 → 各自的列、记录和筛选 → 统一导出
```

### 创建和编辑表格

1. 点击页面上方或左侧的“新建表格”。
2. 输入表格名称，例如 `需求跟踪` 或 `关键风险`；创建后它会直接出现在当前页面。
3. 在该表格右上角点击“添加列”，填写业务列名并选择类型。
4. 直接修改表头文字即可重命名列；直接修改表格标题即可重命名表格。
5. 在表格最后一行输入内容并点击“新增”。已有单元格在失去焦点后自动保存。

每个数据库都有自己的字段和业务用语。例如：

- `需求跟踪` 可以包含需求号、需求名称、进展、交付计划、责任人和状态。
- `关键风险` 可以包含风险描述、风险消减措施、计划关闭时间、责任人和状态。

一个数据库的字段变化不会影响其他数据库。字段重命名不会丢失已有数据，因为记录内部使用稳定字段 ID，而不是字段名称。

### 状态和完成标记

状态字段可以使用 `Open`、`Closed`、`Suspended` 等自定义选项。若要在报告中排除已完成事项，需要在数据库的状态字段中明确勾选哪些状态代表“已完成”。系统不会根据状态名称自行猜测。

### 筛选

每张表格右上角都有独立“筛选”入口。筛选保存该表格当前的：

- 可见字段、字段顺序和宽度
- 筛选条件及嵌套的 `AND`/`OR` 组合
- 排序方式
- 是否显示归档记录

修改一张表格的筛选不会影响页面上的其他表格。底层仍以独立数据库和保存视图存储，因此筛选结果会一致地进入 Excel 和 Outlook 导出，但这些内部概念不需要手工配置。

## 4. 周报和导出

点击页面顶部的“导出”，可设置报告标题、报告周期和是否包含已完成事项，然后选择 Excel 或 Outlook 输出。

### 可编辑 Excel

“下载可编辑 Excel”会为每个导出模块创建独立工作表：

- 数据区域不合并单元格
- 表头冻结并带筛选
- 日期和数字保持对应的数据类型
- 适合继续排序、筛选和编辑

### 展示版 Excel

“下载展示版 Excel”会把不同字段数量的模块放在同一个报告工作表中。应用使用 60 列基础网格自动计算并合并每个业务字段的宽度，适合直接形成周报或打印材料。

### 经典 Outlook 草稿

“创建 Outlook 草稿”会打开一个可见的新草稿，并插入当前报告。应用不会填写收件人，也没有自动发送路径。请检查收件人、主题、内容和原有签名后，由你自行点击发送。

如果经典 Outlook 自动化不可用：

1. 使用“复制邮件内容”，在 Outlook 新邮件中粘贴富文本；或
2. 使用“下载 Outlook HTML”，在浏览器中打开后复制到邮件。

## 5. 备份

打开左侧“设置与备份”，点击“下载工作区备份”即可下载 `.pmdbackup` 文件。备份包含数据库、字段、记录、视图、看板和设置，并带有完整性校验。

建议在以下时间手动备份：

- 第一次正式录入大量数据后
- 每次周报完成后
- 升级应用之前
- 批量调整结构或恢复其他备份之前

将备份复制到受保护的其他磁盘或单位批准的存储位置。自动的迁移前、恢复前备份用于本机安全回滚，不能代替异地手动备份。

## 6. 从备份恢复

恢复会完整替换当前工作区，请先确认备份时间和工作区名称。

1. 点击“从备份恢复”，选择 `.pmdbackup` 文件。
2. 等待系统完成文件格式、校验值、SQLite 和迁移兼容性检查。
3. 核对页面显示的备份时间、应用版本、工作区名称和文件大小。
4. 勾选“我已确认备份信息，并理解当前工作区将被完整替换”。
5. 确认恢复。系统会先创建当前工作区的恢复前备份，然后进入只读状态。
6. 再次双击 `start-dashboard.cmd`。启动器会安全重启后端并应用备份。
7. 检查恢复完成提示，并核对数据库、视图和看板。

如果恢复后的启动验证失败，系统会自动回滚到恢复前的数据。不要手工替换 `workspace.sqlite` 或删除恢复暂存文件；请先保留日志和备份以便排查。

## 7. 升级

1. 在旧版本中下载一份手动 `.pmdbackup`。
2. 完整停止旧版本，并保留旧 ZIP、旧解压目录和升级前备份。
3. 将新版本 ZIP 解压到新的版本目录，不要覆盖旧目录中的文件。
4. 运行新版本的 `verify-release.cmd`。
5. 运行新版本的 `start-dashboard.cmd`。
6. 打开“本机诊断”，确认版本、数据库和迁移状态正常，再检查代表性数据库及导出功能。

不同版本共享 `%LOCALAPPDATA%\ProjectManagerDashboard` 中的数据。若新版本包含数据库迁移，应用会在迁移前自动创建并验证备份，迁移只执行一次。

升级出现问题时，先停止应用并保留日志。要回到旧版本的数据状态，应使用升级前创建的手动备份；不要用旧程序直接修改已经迁移过的新数据库。

## 8. 更换电脑

1. 在旧电脑下载最新 `.pmdbackup` 并安全复制到新电脑。
2. 在新电脑解压并验证相同或更新版本的便携包。
3. 启动一次应用，让本地数据目录完成初始化。
4. 按“从备份恢复”的步骤导入备份并重新启动。
5. 核对数据库、视图、看板以及 Excel/Outlook 导出。

## 9. 本机文件位置

默认数据根目录为：

```text
%LOCALAPPDATA%\ProjectManagerDashboard
```

主要内容包括：

| 路径 | 用途 |
| --- | --- |
| `workspace.sqlite` | 当前工作区数据库 |
| `backups` | 迁移前和恢复前自动备份 |
| `logs` | 启动器和本地服务日志 |
| `restore-staging` | 已检查、等待重启应用的恢复文件 |
| `launcher-state.json` | 当前本地服务的启动状态和停止认证信息 |

正常的 Excel、HTML 和 `.pmdbackup` 下载由浏览器保存到浏览器配置的下载目录。不要编辑上述内部文件，也不要把数据目录放进发布包目录。

## 10. 故障处理

| 现象 | 处理方法 |
| --- | --- |
| `verify-release.cmd` 失败 | 发布文件已缺失或被修改。保留数据目录，从原始 ZIP 重新解压到新目录，不要编辑完整性清单。 |
| 启动后浏览器没有打开 | 手动访问 `http://127.0.0.1:4300`；仍不可用时查看 `%LOCALAPPDATA%\ProjectManagerDashboard\logs`。 |
| 提示端口属于其他服务 | 停止占用 `127.0.0.1:4300` 的其他程序后重试。不要修改清单绕过检查。 |
| 公司策略阻止 PowerShell 或便携程序 | 不要使用 `ExecutionPolicy Bypass`。将提示交给单位 IT，申请允许受信任发布目录中的签名/受控脚本。 |
| Outlook 草稿无法创建 | 确认使用 Windows 经典 Outlook并已完成账户配置；随后使用富文本复制或 HTML 下载备用方式。 |
| Excel 提示修复文件 | 不要继续编辑该文件；保留原始下载和日志，改用另一种 Excel 模式并报告问题。 |
| 恢复后显示已自动回滚 | 当前数据仍是恢复前版本。保留所选备份和日志，检查备份兼容性后再处理。 |
| 怀疑数据异常 | 立即停止应用，复制整个 `%LOCALAPPDATA%\ProjectManagerDashboard` 到安全位置，再进行恢复或排查。 |

## 11. 首版边界

- 仅支持一个人在一台本机上使用，不提供多人实时协作或局域网访问。
- 不依赖 Notion 或其他外部 SaaS，不提供云同步和遥测。
- 关系、汇总、公式字段以及 CSV/XLSX 导入将在后续版本考虑。
- 首版看板采用纵向全宽模块；多列自由布局、日历、时间线和提醒不在 0.1.0 范围内。
- Outlook 集成只创建并显示草稿，永不自动发送。
